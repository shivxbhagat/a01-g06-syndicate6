# Smile

Smile - Your University Only Marketplace by Syndicate6

## Presentation

Users have to run it locally on their machine. Make sure to have internet connection and the website best works on Chrome with desktop view.

```bash (for MacOS)
git clone https://code.cs.umanitoba.ca/comp3350-winter2025/a01-g06-syndicate6.git
cd a01-g06-syndicate6
open index.html
```

or

```bash (for Windows PowerShell)
git clone https://code.cs.umanitoba.ca/comp3350-winter2025/a01-g06-syndicate6.git
cd a01-g06-syndicate6
Start-Process "index.html"
```
